# Formatter emoji

Twemoji graphics by Twitter, Inc. and contributors, from
https://github.com/twitter/twemoji/tree/v14.0.2/assets/svg.

Graphics are licensed under Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/. See LICENSE-GRAPHICS.

Technical conversion: SVG artwork rasterized at 512 x 512 and reduced to
128 x 128 RGBA PNG with box filtering. Original colors are retained.
These local assets are used only for add-on formatter text; no emoji font
or runtime download is required.
